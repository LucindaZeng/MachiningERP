# 香港代生产客户正式订单70%价格规则

> 本文件由 `tools/build_hong_kong_orders.py` 根据 `tools/hong_kong_orders.py` 生成，是ERP V2.0客户价格规则研发基线。

## 核心原则

- 香港代生产不是一种独立订单类型，也不增加独立业务流程；只在客户主数据上设置“香港代生产价格客户”勾选项。
- 价格转换的唯一触发条件是：订单所选客户已勾选“香港代生产价格客户”，并且订单类型为“正式业务订单”。两个条件必须同时成立。
- 业务录入客户给出的原始单价和金额后，系统按固定系数70%自动计算本公司正式业务订单单价与金额；计算结果作为该订单后续审核、应收、成本毛利及经营分析使用的业务价格。
- 即使客户已被勾选，模具订单和样品订单也不得乘70%，仍完整保留业务实际输入的价格；其他未勾选客户的所有订单同样保持原输入价格。
- 系统同时保留原始输入价格、价格系数70%、计算后订单价格、客户勾选状态快照、订单类型快照和计算时间，便于审核和追溯，但不另外建立30%分成、香港留存或特殊结算流程。
- 除正式业务订单价格自动换算外，BOM申请、工程建BOM、业务经理审核、财务审核、订单评审、MRP、采购、生产、品质、委外、包装、报关、发货、开票、收款和成本核算全部沿用普通正式订单流程。
- 客户、订单类型、数量、原始单价或币种变化时，系统重新判断触发条件并生成新价格版本；已经审核或已发生下游业务的订单不得静默覆盖原价格。

## 必填字段

| 分组 | 字段与口径 |
| --- | --- |
| 客户主数据 | 客户编码、客户名称、香港代生产价格客户勾选项、固定价格系数70%、启用/停用状态、申请人、审核人、生效时间和变更原因。 |
| 订单识别 | 业务订单号、客户、订单类型（模具/样品/正式）、订单状态、原始客户订单/核价附件及客户勾选状态快照。 |
| 原始价格 | 业务实际输入的原始单价、原始数量、原始金额、含税/未税口径、币种、税率和汇率；原始价格不得被70%计算结果覆盖。 |
| 计算后价格 | 触发条件是否成立、价格系数70%、计算后单价、计算后金额、舍入规则、计算时间、价格版本和计算服务版本。 |
| 下游引用 | 订单审核价、应收价、收入管理口径、成本毛利分析价及相关单据引用的价格版本；其他流程字段与普通正式订单一致。 |
| 审计信息 | 客户勾选、取消勾选、客户切换、订单类型切换、原价修改、自动重算、人工例外申请及审核前后值。 |

## 价格计算

| 指标 | 计算 | 控制 |
| --- | --- | --- |
| 触发判断 | 客户已勾选 AND 订单类型=正式业务订单 | 仅两个条件同时满足才执行70%转换。 |
| 正式订单单价 | 业务输入原始单价×70% | 按企业统一的小数位和舍入规则计算，不允许业务手工重复乘70%。 |
| 正式订单金额 | 计算后单价×正式订单数量 | 税额、折扣和汇率按普通订单既有规则处理。 |
| 样品/模具订单价格 | 业务输入原始单价×100% | 即使客户已勾选也不执行70%转换。 |
| 其他客户订单价格 | 业务输入原始单价×100% | 未勾选客户不执行任何香港价格规则。 |
| 价格版本核对 | 原始价格×适用系数=计算后价格 | 不相等、系数重复应用或原始价格缺失时禁止提交审核。 |

## 完整流程

1. 由授权人员在特定客户的客户主数据上勾选“香港代生产价格客户”；普通客户不勾选。
2. 业务选择客户并新建订单，系统读取客户勾选状态，但此时不改变BOM、交期、贸易、生产或其他流程。
3. 业务选择订单类型并输入客户订单上的原始单价、数量和币种，系统保留原始输入值。
4. 若客户已勾选且订单类型为正式业务订单，系统自动显示“原始单价、70%系数、计算后正式订单单价”；否则计算后价格等于原始输入价格。
5. 业务提交订单时，系统校验客户快照、订单类型、原始订单/核价附件、原始价格和计算后价格，防止漏算、重复乘70%或错误应用到样品/模具订单。
6. 业务经理仍按普通业务订单规则审核客户、数量、价格、交期和附件；财务仍按普通规则审核核价、原始订单、付款条件、税率、币种和毛利。
7. 订单通过后仍执行原有订单评审、PMC运行MRP、采购、收料、品质检验、切料、CNC/车床、逐工序品质、后工序、委外、全检包装等完整流程。
8. 报关资料仍由系统按现有外贸规则生成；本规则不增加特殊报关步骤，也不允许用客户勾选绕过已有报关审核。
9. 发货、开票、应收、收款、成本归集、工序成本和订单毛利继续使用普通正式订单流程，并引用已审核的计算后订单价格版本。
10. 客户、订单类型或原始价格变更时系统自动重判并重算；已审核订单必须走订单变更及重新审核，历史版本永久保留。

| 客户价格规则变更记录 | 客户勾选/取消勾选、固定70%系数、申请审核、生效时间、原因及前后值。 |
| 业务订单价格计算明细 | 订单行、原始单价、原始金额、客户勾选快照、订单类型、适用系数、计算后单价和金额。 |
| 订单审核单 | 沿用普通订单审核单，在价格区域增加原始价格、70%计算依据和计算后价格，不另建特殊审批单。 |
| 价格转换异常清单 | 漏算、重复计算、样品/模具误算、客户切换未重算、版本不一致和人工改价尝试。 |
| 香港客户正式订单价格审计表 | 按客户、订单和版本展示原始输入价格、70%后价格、差额、审核人及下游引用状态。 |

## 审批权限

- 客户主数据的香港代生产价格勾选项只能由授权岗位申请和维护，启用、取消或变更必须记录原因并经业务负责人/财务按企业权限审批。
- 业务可以录入原始客户价格，但不能直接修改固定70%系数或覆盖系统计算后价格；确需例外时按普通订单价格例外流程审批。
- 业务经理继续执行普通订单审核，重点确认客户选择、订单类型和原始客户订单；财务继续执行普通财务审核，重点确认核价、原始价格、计算结果和毛利。
- 样品订单和模具订单即使选择该客户也不执行70%转换；其免费、部分收费或收费审批继续沿用三类订单原有规则。
- 已审核订单修改客户、订单类型、原始单价、数量或币种时撤销原价格放行状态，自动重算并按普通订单变更流程重新审核。
- 客户勾选只影响符合条件的正式业务订单价格，不授予任何额外数据权限，也不改变生产、品质、采购、报关、开票和收款岗位权限。

## 预警

- 客户已勾选且订单类型为正式业务订单，但计算后价格不等于原始输入价格的70%。
- 客户未勾选，或订单类型为样品/模具，却错误应用70%系数。
- 原始输入价格、客户勾选状态快照、订单类型快照或计算版本缺失，导致价格不可追溯。
- 业务人员手工把原价先乘70%后录入，系统又自动乘70%，形成疑似重复折算。
- 订单更换客户、切换订单类型或修改原始价格后未重新计算、未重新审核或下游仍引用旧版本。
- 已审核计算后价格被直接修改，或订单、应收、开票、毛利分析引用的价格版本不一致。
- 70%后的正式订单价格低于预计成本或目标毛利阈值时，继续触发普通正式订单的毛利预警与审批。

## 部门责任

| 角色 | 责任 |
| --- | --- |
| 业务/销售 | 选择客户和订单类型，录入原始客户价格并核对系统70%结果；不手工修改系数或计算后价格。 |
| 业务经理 | 沿用普通订单审核，确认客户、正式订单类型、原始客户订单、输入价格和70%计算结果。 |
| 财务部 | 沿用普通财务审核，确认核价、原价、计算价、币种税率、付款条件及计算后价格对应的订单毛利。 |
| 工程/PMC/采购/生产/品质/仓库/委外 | 完全按普通正式业务订单执行BOM、MRP、采购、生产、品质、委外、库存和交付，不新增香港专用步骤。 |
| 外贸/关务 | 完全沿用既有报关资料生成、复核和版本流程；客户价格勾选不改变报关岗位权限或其他业务字段。 |
| 系统管理员/主数据岗位 | 维护客户勾选项的权限、变更日志和生效控制；不能代替业务或财务审核订单价格。 |
