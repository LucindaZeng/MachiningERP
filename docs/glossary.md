# 术语表

| 术语 | 定义 |
| --- | --- |
| APS | 考虑有限产能、资源和优先级的高级计划与排程 |
| ASN | 供应商发货前提交的预到货通知 |
| BOM | 产品的物料组成、数量、损耗和版本结构 |
| CAPA | 纠正与预防措施 |
| ERP | 经营交易、资源计划、供应链、财务与成本系统 |
| FAI | First Article Inspection，新产品、打样或重大变更时的首件鉴定与报告 |
| MES | 车间派工、执行、报工、异常和设备数据系统 |
| MRP | 根据需求、库存、在制、在途、提前期和损耗计算净需求 |
| MRB | 对不合格品进行评审和处置的机制 |
| OEE | 时间开动率×性能开动率×合格率 |
| PLM | 产品、图纸、BOM、工艺和工程变更管理 |
| QMS | 检验、不合格、改进、计量和质量追溯系统 |
| SRM | 供应商询报价、订单、交付、质量和结算协同 |
| WMS | 仓库收货、上架、库位、拣配、盘点与条码防错 |
| 一码到底 | 原料批次、工单、流转批次或单件码贯穿生产、质量、库存和交付 |
| 路线 A | 跨序退回返工后，在质量放行后直接返回发现问题的工序 |
| 路线 B | 跨序退回返工后，必须从返工下一工序开始按顺序重新流转 |
| 行情快照 | 业务单据使用的价格、汇率、时间、来源、许可和换算参数的不可变记录 |
| 企业落地价 | 市场基准经汇率、升贴水、加工、物流和税费换算后的企业参考采购价 |
| 指标语义层 | 对指标公式、时间、维度、权限、来源和负责人进行统一管理的查询层 |
| 工作中心 | 用于产能、派工、报工、费率和成本归集的生产或服务执行单元 |
| 末件检 | 批次、换班或换型结束前对最后加工件的检验，用于发现过程漂移 |
| 劳务结算 | 基于审核考勤、有效工时/计件、合同费率、补贴和扣款形成的外部劳务对账与应付 |
| 香港代生产价格客户 | 客户主数据中的受控勾选属性；只有该属性为是且订单类型为正式业务订单时，系统才把业务输入价格按70%生成订单价格 |
| 香港正式订单计算价 | 已勾选客户的正式业务订单价格，等于业务输入原始价格×70%；样品、模具及未勾选客户均使用原始输入价格 |
| 工序执行实例 | 某批次在某路线版本下对一道工序的一次实际执行记录；返工、重做或重复执行必须生成新实例并重新计费 |
| 工序新增成本 | 该工序本次执行产生的材料、人工、机器、刀具工装、委外、检验、物流包装、制造费用和异常等成本 |
| 工序累计成本 | 上道工序转入累计成本加本工序新增成本及批准调整后，随合格数量转入下一工序的成本 |
