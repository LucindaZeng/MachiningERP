# 术语表

| 术语 | 定义 |
| --- | --- |
| APS | 考虑有限产能、资源和优先级的高级计划与排程 |
| ASN | 供应商发货前提交的预到货通知 |
| BOM | 产品的物料组成、数量、损耗和版本结构 |
| CAPA | 纠正与预防措施 |
| ERP | 经营交易、资源计划、供应链、财务与成本系统 |
| MES | 车间派工、执行、报工、异常和设备数据系统 |
| MRP | 根据需求、库存、在制、在途、提前期和损耗计算净需求 |
| MRB | 对不合格品进行评审和处置的机制 |
| OEE | 时间开动率×性能开动率×合格率 |
| PLM | 产品、图纸、BOM、工艺和工程变更管理 |
| QMS | 检验、不合格、改进、计量和质量追溯系统 |
| SRM | 供应商询报价、订单、交付、质量和结算协同 |
| WMS | 仓库收货、上架、库位、拣配、盘点与条码防错 |
| 一码到底 | 原料批次、工单、流转批次或单件码贯穿生产、质量、库存和交付 |
| 路线 A | 跨序退回返工后，在质量放行后直接返回发现问题的工序 |
| 路线 B | 跨序退回返工后，必须从返工下一工序开始按顺序重新流转 |
| 行情快照 | 业务单据使用的价格、汇率、时间、来源、许可和换算参数的不可变记录 |
| 企业落地价 | 市场基准经汇率、升贴水、加工、物流和税费换算后的企业参考采购价 |
| 指标语义层 | 对指标公式、时间、维度、权限、来源和负责人进行统一管理的查询层 |
