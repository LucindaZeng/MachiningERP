详细字段、流程、规则和验收证据见 [Word 规划方案](../制造业ERP软件规划方案_V2.3.docx)。十三部门的功能、审核权限、预警和报表见 [部门控制矩阵](department-control-matrix.md)，订单节点及模具/样品/正式订单收费规则见 [订单全生命周期](../workflows/order-to-pack-lifecycle.md)，返工拆单与责任成本规则见 [返工成本归集](../workflows/rework-cost-accounting.md)，香港客户正式订单价格换算见 [香港客户价格规则](../workflows/hong-kong-manufacturing-orders.md)，每道工艺独立成本规则见 [工序级成本](../features/operation-level-costing.md)。本文件用于把需求分解到 GitHub Issue、实现和测试。

## Epic

| Epic | 需求前缀 | 范围 | 首要验收 |
| --- | --- | --- | --- |
| 项目治理 | GOV | 范围、RACI、变更、风险、上线与回退 | 阶段门和真实业务 UAT |
| 组织与部门 | ORG | 十三部门、岗位、工作中心、数据责任和权限 | 十三部门工作台及跨部门交接UAT |
| 订单全生命周期 | OTL | 报价、工程准备、订单审核、评审、MRP、采购、生产、品质、委外、包装与节点时效 | T0至T1逐节点计时、预警和数量交接UAT |
| 主数据与工程 | MDM | 物料、图纸、BOM、工艺、设备、工装和版本 | 工单使用唯一有效版本 |
| 报价与合同 | QTN | 询价、成本、报价、审批、合同和订单 | 系统生成报价 PDF 并转订单 |
| 香港客户价格规则 | HKO | 客户级勾选、正式订单原价×70%、样品模具及其他客户保持原价、价格版本和普通流程复用 | 四组正反案例、变更重算、防重复折算和价格外流程不变全部通过 |
| PMC/MRP/APS | PMC | 净需求、齐套、计划、排程与资源冲突 | 每条建议可解释并追溯需求源 |
| 采购与供应商 | SRM | 在线报价、比价、订单、进度、ASN、质量和对账 | 供应商网页报价到送货闭环 |
| 金属材料价格 | MKT | 行情、供应商价、成交价、落地价、快照和预警 | 三角色视图、历史重现和许可审计 |
| 生产执行 | MES | 扫码、工序防跳、跨序返工、返工子订单、设备与绩效 | 两类返工路线、数量拆分、重复工序成本和责任归集跑通 |
| 工序级成本 | OPC | 每道工艺独立成本卡、转入/新增/累计成本、标准实际差异、在制、报废和返工 | 全部工序成本之和等于订单实际成本且可下钻源单 |
| 品质 | QMS | 首检、巡检、末件、FAI、冻结、MRB、CAPA、放行与追溯 | 原始测量、版本、报告和质量门禁 |
| 仓储 | WMS | 收货、库位、批次、余料、备料、盘点和呆滞 | 数量、状态、批次和库位一致 |
| 财务与成本 | FIN | 总账、往来、资金、费用、资产、税务、预算、返工和制造成本 | 业务到凭证、返工毛成本/回收/净损失到订单毛利可勾稽 |
| 行政考勤与劳务 | ADM | 人员、班次、打卡、异常、报表和多劳务结算 | 考勤到劳务对账、应付全链路 |
| 单据与报表 | DOC | 模板、生成、版本、快照和正式文件 | 无需人工拼接关键 Excel |
| 预警中心 | ALT | 临期、超期、升级、原因、措施和关闭 | 责任、SLA、升级和审计完整 |
| 客户协同 | CUS | 客户项目、交付、文件和质量 | 客户数据完全隔离 |
| 指标分析 | BI | 指标字典、驾驶舱、钻取和根因 | 汇总数字可钻取源单 |
| AI 分析问答 | AIX | 财务/老板问答、模拟、引用、权限和审计 | 固定问题与正式报表一致且不越权 |
| 安全与非功能 | SEC | 权限、接口、性能、容灾、审计和运维 | 安全、恢复和性能测试通过 |

## 需求状态

每项需求使用以下状态：

1. `Proposed`：已提出，尚未业务确认。
2. `Approved`：业务、IT 和相关控制岗位确认。
3. `Designed`：流程、数据、接口、权限和验收设计完成。
4. `In Development`：进入实现。
5. `Ready for UAT`：开发和集成测试通过。
6. `Accepted`：真实业务 UAT 有证据通过。
7. `Deferred`：明确移出当前阶段并保留原因。

## Issue 必填信息

- 需求编号、角色、组织与触发事件；
- 前置条件、主流程、替代流程、失败和撤销；
- 输入、输出、状态、版本、编号和审计；
- 权限、职责分离和敏感字段；
- 接口、报表、预警与 AI 影响；
- 验收数据、期望结果和证据类型；
- 迁移、兼容、性能、监控和回退影响。

## 基线变更

影响金额、库存、工艺、质量放行、客户/供应商可见数据或财务口径的需求，不得只在代码中改变。应先批准 Issue/ADR，再同步更新 Word 方案、Markdown、测试和变更日志。
