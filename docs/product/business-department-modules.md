# 业务部模块需求规格

> 依据业务负责人口述需求（2026-07-28 初版，2026-07-31 增补24条）整理，结合《制造业ERP软件规划方案 V2.4》业务部章节与 `example/` 目录下的成本分析、报价单模板。成本分析格式以 `example/成本分析/CNC成本分析.xls` 为准，报价单格式以 `example/报价单模板/国内报价单.xls`、`国外报价单.xlsx` 为准。开发顺序位于「模块开发顺序」第2步（业务部模块）。

业务部功能分为十一个模块：**业务工作台、报价管理（含成本核算与原材料价格表）、订单管理（含订单追踪）、客户信息管理、BOM申请、ECN申请、出货管理、退货管理、发票申请、报关资料、数据分析**。

## 1. 业务工作台

各业务员登录后的首页，数据按业务员权限过滤（业务经理可见本部门全部）。

- 待办中心：待报价询价、成本分析完成待生成报价单、报价待业务经理审核、报价待客户确认、报价修改申请待处理、BOM 建立完成通知、订单待审、图纸变更（ECN）待确认、出货计划临期、发票申请状态、退货/客诉待处理。
- 通知流：成本分析完成通知、BOM 完成通知、订单审核结果、报价修改申请结果（含驳回理由）、ECN 审批结果。
- 关键指标卡：本月报价数/成交率、在手订单额、临期交货、逾期应收（引用财务数据只读）。
- 快捷入口：新建报价、新建订单、BOM 申请、ECN 申请、发票申请。

## 2. 报价管理（含成本核算与原材料价格表）

### 2.1 功能组成

- **新建报价**（报价申请 → 成本分析 → 报价单生成 → 审核）
- **报价单条件搜索**：按客户、名称图号、材质、表面处理、日期区间、业务员、状态（草稿/审核中/生效/已成交/未成交/已失效）、金额区间等条件组合搜索曾经的报价单。
- **过往报价查询**：每条历史报价打开后同屏展示三层信息：
  1. **当时的报价单**：报价版本快照（价格、阶梯价、模具费、币种、汇率、有效期、审批记录），只读；
  2. **当时的成本分析**：该报价版本对应的成本分析快照（材料单价取当时价格表、工艺成本列、损耗与管理费比例），只读；
  3. **实际成本回溯（追溯到每一个工艺）**：若该报价已成交转订单，回溯关联订单的实际生产成本，且必须**逐工艺展开**——材料、切料、CNC/车床、打磨去毛刺、抛光、表面处理（委外）、镭雕丝印、组装、全检包装等每道工艺显示各自的实际单件成本（数据来自工序级成本卡：工时、费率、委外价、检验、损耗分摊）；工艺行与成本分析的工艺成本列一一对齐，逐工艺显示"报价成本 vs 实际成本"偏差，汇总层再显示总成本、成交价与毛利偏差，精确定位是哪道工艺报错了价；未成交或未完工的显示相应状态。
  - 报价、成本分析与订单实际成本通过版本快照关联，历史数据不随价格表、汇率更新而变化。
- **材料价格查询**：原材料价格表（材质、规格/形态、单价、生效日期、来源），由授权岗位维护；新建报价与成本分析界面内嵌显示。
- **当日汇率查询**：当日汇率表；在新建报价界面与「成本分析→国外报价单」转换界面均须内嵌显示。

### 2.2 报价流程与职责分工

1. 业务提起报价申请，选择**新客户/老客户**（老客户从信息库导入；新客户填公司名、联系人、联系方式）。
2. **业务只需提供两样东西：图纸和数量**（数量可为阶梯、也可为非阶梯单一数量）；**报价单必须强制上传图纸**，缺图纸不能提交申请。
3. 图纸进入系统图纸库后自动流转：**传给报价工程师用于成本分析报价，同时传给工程部用于后续 BOM 建立**——同一份图纸，两处引用，不重复上传。
4. **成本分析（成本核算）只有报价工程师角色才能做**，业务员无权创建或修改成本分析；报价工程师完成剩余全部资料填写（材质、尺寸、重量、工艺、费率等）。
5. 成本分析完成后系统通知业务员生成报价单。
6. **每一份报价单强制关联成本分析**：无成本分析的报价单不能创建、不能提交审核（系统硬校验）。
7. 业务员生成报价单，提交业务经理审核；审核通过后报价单生效并可导出发客户。

### 2.3 成本分析（格式以 CNC成本分析.xls 为准）

- 表头：客户名称、产品型号。
- 每个零件一行，字段：序号、毛料类型（板料/型材/棒料等）、**名称图号**、**图片（上传）**、**规格型号（尺寸）**、**版本号**、数量、材质、预估重量/KG、净重/KG、余料/KG、余料单价、材料单价、材料金额、机加方式、加工时间、加工金额。
- **工艺成本列可自由加减**（默认：打磨去毛刺、抛光、表面处理、镭雕丝印、组装安装、全检包装运输；可按产品增删工艺列）。
- 汇总列：损耗（默认5%，可调）、管理费利润（默认5%，可调）、合计金额、含税（13%）金额、备注、预计单价、调比。
- **模具费不计入单件成本分析**，作为报价单中的单列项（见2.4）。
- 材料单价从原材料价格表带出（可手改并留痕）；国外报价按当日汇率换算。
- **相似产品匹配**：录入名称图号、材质、尺寸、工艺后，系统按结构化特征（客户＋材质＋尺寸范围＋工艺组合）匹配过往相似成本分析与报价，供报价工程师参考引用。首期为规则匹配，不引入外部 AI API；图纸图形相似度识别列为二期专项。

### 2.4 报价单生成（统一模板）

- 成本分析与国内/国外报价单均**按统一模板**由系统生成，模板即 `example/报价单模板/` 两份文件的系统化版本：
  - 国内报价单：中文，含币别（RMB/USD/HKD）、代工方式、付款方式、允许报废率、废料退还、有效期限、客户回签栏；
  - 国外报价单：英文 Quotation，含 Supplier/Buyer、Item/Rev/Material/Finishing/MOQ、Tolling、Remark。
- **阶梯价格**：按数量段报价（如样品 10/30/50、批量 100/200/500/1000），数量段可配置；也支持非阶梯单一数量报价。
- **模具费单列**：报价单上模具费为独立行项，不摊入单件价。
- 业务员可自由填入最终报价价格；**低于成本价时系统提示，要求修改成本分析**。
- 国外报价单界面显示当日汇率，并按汇率将成本分析（RMB）转换为外币报价参考。
- 报价单完成后提交**业务经理审核**，审核通过后锁定版本；改价需生成新版本重新审核。
- **导出**：报价单和成本分析表都可导出为 Excel；并支持**多选合并导出**——勾选多份报价单（或多份成本分析）合并导出到一张报价单/一张成本分析表上（多产品行合并到同一表内）。

### 2.5 报价单修改申请

- 业务提起**报价单修改申请**，直接填入修改后的目标价格及理由。
- 报价工程师处理：**修改成本分析**（重新核价，生成成本分析与报价新版本）或**驳回申请（必须填写驳回理由）**。
- 处理结果通知业务员；驳回理由在工作台通知与申请单上可见。
- 打样阶段的图纸变更也走此入口（图纸修改申请），报价工程师重新确认价格。

## 3. 客户信息管理

### 3.1 客户档案字段

| 字段 | 规则 |
| --- | --- |
| 客户编号 | 系统自动生成（调用平台统一编号规则），不可手改 |
| 客户名称 / 客户简称 | 必填 |
| 负责人 / 负责人电话 | 必填 |
| 负责人邮箱 | 选填 |
| 国内/国外客户 | 必选；**国内客户必填税号** |
| 负责对接的业务人员 | 关联系统业务员账号，驱动工作台数据权限 |
| 发票地址 | 必填 |
| 送货地址 | 可新增多个，**最多不超过5个**，其中一个设为默认 |
| 银行账号 / 开户行 | 收付款与对账引用 |
| 付款条件 | 三选一：① 预付一定比例、剩余出货前付清；② 现金，出货前全部付完；③ 票到30/60/90天 |
| 发票种类 | 普票 / 专票 |
| 结算方式 | 现金 / 票据 |

### 3.2 管理规则

- 新客户在报价阶段只留公司名、联系人、联系方式；**成交下单前必须补全完整档案**方可建立订单。
- 客户档案变更（银行账号、付款条件等敏感字段）留痕并按权限审批。

## 4. 订单管理（含订单追踪）

业务员下单分五种：**正常订单、样品订单、模具订单、备料订单、订单修改申请**。

### 4.1 通用规则

- 所有订单必须由报价单转入产品与价格信息，**环环相扣：必须有生效报价才能下单**。
- **下单强制校验**：下单时产品若缺少报价单、成本分析或任何工程资料（图纸、BOM——样品单除外），系统提示报错并**禁止下单**，明确列出缺失项。
- **客户交期为必填项**（备料订单无客户交期，填内部要求完成时间）。
- **一张订单可下多项产品**：样品订单、模具订单、业务订单、备料订单均支持一单多行产品明细，每行独立数量、单价与交期跟踪；不允许强制一单一品。
- **客户订单原件强制上传**：模具订单、正常业务订单必须上传客户订单原件；样品订单**有价格（收费）的**必须上传订单原件；免费样品和备料订单不要求。
- **品号规则（按《万富鑫物料编码原则》执行，所有物料10位数字码=大类+小类+流水）**：
  - 只有正式订单的产品才建立**成品品号**：大类10＋客户编号4位＋机种编号4位（例 `1008010001` = 801客户的0001号产品）；自制配件用大类11；
  - **样品没有 BOM，也没有成品品号**——样品入库使用**样品大类编码（大类12）**：12＋客户编号4位＋流水4位（例 `1208010001`），入**样品仓（仓库编号400）**；
  - 模具用大类19（按冲压/压铸/锻造/铝挤等工艺分小类）；原材料用大类13（材质中类＋国标/非标）。
- 订单提交后进入审核流（业务经理 → 财务 → 跨部门订单评审，引用平台审批流）。
- 客户确认下单后，业务先提起 BOM 申请（见模块5）；正常订单在 BOM 建立完成后方可排产。

### 4.2 正常订单（批量订单）

- 从报价单引入产品、阶梯价对应的数量与单价；关联客户原始订单（强制上传）。
- 必填：产品明细（可多行）、数量、**客户交期**、付款条件（默认带出客户档案，可按单调整并审批）。

### 4.3 样品订单

- 信息**必须从报价单引入**，不允许在样品单环节重新上传图纸。
- **样品没有 BOM，也没有品号**；样品入库使用通用品号。
- 只需选择**是否免费打样**；收费打样必须上传客户订单原件。
- 打样期间图纸变更：走**报价单修改申请**（见2.5），报价工程师重新确认价格后样品单引用新版本——禁止在样品下单处替换图纸。

### 4.4 模具订单

- 只填**模具要求完成时间**，不设"完成/未完成"状态跟踪；强制上传客户订单原件。
- 模具费来源于报价单的模具费单列项。
- **模具由工程部关联到对应产品上，一个模具可对应多个产品**（多对多关系由工程部维护，业务侧只读查看）。

### 4.5 备料订单

- 备料订单**不含交货义务**：业务部不需要向客户交货，没有客户交期；**产品全部完工入库即视为订单完成**。
- 从报价单引入产品信息（与其他订单一致，必须先有生效报价）。
- **与正式订单的关联与消耗**：下正式业务订单时可关联对应的备料订单；正式订单需求优先消耗备料库存，**直到备料产品被用完**，不足部分由正式订单继续生产。备料剩余数量与被哪张正式订单消耗的履历全程可查。
- **成本规则**：备料订单的生产成本口径与交付它的正式业务订单相同。正式订单的平均生产成本按加权平均计算：

  > 平均生产成本 =（备料单件成本 × 消耗备料数量 + 本单单件生产成本 × 新生产数量）÷ 订单总数量
  >
  > 例：正式订单下单100个，备料单剩余20个（单件成本10元），继续生产80个（单件成本12元），则平均生产成本 =（10×20＋12×80）÷100 = **11.6元/件**。

- 财务口径：备料订单完工入库形成库存资产、不产生应收；成本先归集在备料订单，被正式订单领用时按上述加权规则结转到正式订单成本。
- **审批控制**：备料订单属于无客户订单支撑的库存投入——业务提出用途与预期消耗，业务经理确认必要性，财务审核资金占用，**无论金额大小必须经总经办批准**后方可下达。

### 4.6 订单修改申请

- **适用范围（与 ECN 的分界）**：改数量、改交期等**订单信息**在订单管理里申请订单修改；**改图、改材料、改表面处理属于 ECN**（见模块6），不走订单修改。
- **锁定字段：现有订单的价格和下单产品不能被修改**——订单修改申请只能改数量、交期等；如需改价或换产品，须先走报价单修改申请（2.5）形成新报价版本，再按新订单/订单换版处理（见待确认事项）。
- 提交后走重新审批，变更留痕并保留原版本。

### 4.7 订单追踪

- **目的**：让业务及时查询每张订单/每个产品行进行到哪个环节；**业务部、总经办、PMC 三方均可查看**（按各自数据权限）。
- **追踪起点：订单评审**。标准追踪链（按产品工艺路线自动裁剪）：

  > 订单评审 → PMC跑生产计划 → 采购计划 → 到料 → 原材料品质检（IQC）→ 切料 → 调机 → 首件检测 → 车床 → 品质检 → CNC → 品质检 → 打磨 → 品质检 → 仓库（交接）→ 委外表处 → 仓库（回料）→ 品质检 → 镭雕丝印 → 品质检 → 包装 → 出货报告 → 入库

- 每个节点显示：状态（未开始/进行中/已完成/异常）、开始与完成时间、责任部门；数据来自 MES 扫码、检验记录和仓库过账，不允许手工填报进度。
- **工单进度条按数量显示**：每一个工艺的进度显示为**完成数/工单数**（如 58/100），**不使用百分比**。
- 一单多产品时，按产品行分别追踪；订单头显示各行汇总状态。
- 异常节点（检验不合格、停滞超时）高亮并联动预警中心。

## 5. BOM 申请

- 客户确定下单后，业务提起 BOM 申请，**直接引用报价单内的产品**（名称图号、版本、材质自动带入；图纸由报价环节上传的版本自动传给工程，不重复上传）。
- **一张 BOM 申请对应一个产品**（多产品时从同一报价单批量勾选、一次生成多张申请，各自独立跟踪）。
- 申请单流转给工程部；状态模型采用**双线并行开关**（对应 ENG-03 建BOM/工艺 与 ENG-04 程序编制验证，两线可并行）：`bomReady` 与 `programReady` 独立标记，**两者都完成才算"全部工程完成"**，工艺路线或程序未完成不得按全部完成处理；申请级状态含待接收/建立中/已完成/退回（退回须填理由）等。
- **两级完成信号**：①BOM 建立完成（bomReady）时即通知对应业务员「BOM 建立完成，可下单」，正常/备料订单自此可下单排产——程序编制（ENG-04）与订单审批、采购备料并行，不挡下单；②工艺路线与程序全部完成（全部工程完成）时发出工程完成播报，作为未来生产开工校验与工程统计的依据。
- 样品订单不走 BOM 申请（样品无 BOM）。

## 6. ECN 申请（工程变更）

- **适用范围**：**改图纸、改材料、改表面处理**属于 ECN；改数量、改交期等订单信息走订单修改申请（4.6）。
- 业务侧发起：提交 ECN 申请，上传新版图纸（旧版保留，版本递增）。
- 打样阶段的图纸变更走「报价单修改申请」路径（2.5），由报价工程师重新核价后更新报价版本。
- **设变影响分类（两种情况，工程评估时必选其一）**：
  1. **对生产无影响**：不需要做具体区分，走常规审批后直接生效；
  2. **对生产有影响**：**PMC 必须统计已生产数量并录入系统**——判定口径：**只要生产（车床/CNC）动了，该产品即计入受影响数量**（未上机的不计）；受影响数量录入后**走返工流程**处理。有生产影响的 ECN 在 PMC 完成数量录入并发起返工前不得结案。
- 批量订单阶段的变更由工程部评估影响（BOM、工艺、在制、库存），业务确认对客户的价格/交期影响后回复客户。
- ECN 审批结果通知业务员；变更后的图纸、BOM、报价版本保持关联可追溯。

## 7. 出货管理

- 出货计划：按订单交期生成待出货清单，业务确认出货批次、数量与收货地址（从客户档案送货地址选择）。
- **一张出货单可包含多项产品**（多行明细，各行关联各自订单行）。
- 出货校验：品质放行结论与财务信用检查（按付款条件：预付/现金客户未收款到位时阻断出货）通过后方可过账。
- 出货单据：送货单、装箱单由系统生成；国外订单联动报关资料模块。
- 出货后状态回写订单（部分出货/全部出货），并推送应收依据给财务。
- **客户对账单生成**：按客户和期间自动汇总出货明细、发票、收款、退货折让和未收余额，生成对账单（PDF/Excel）供客户确认回签；数据与财务应收一致，业务不得手工修改金额，对账差异回到源单处理并留痕。

## 8. 退货管理

- 客诉与退货登记：关联原订单、出货批次、名称图号与版本、检验记录；**一张退货单可包含多项产品**。
- **处理决定（disposition，按行）**：退款(refund)、补货(replacement)、返修(rework)、让步使用(concession)、报废(scrap)、待定(undecided)——每行必须在结案前落定；退款是财务结果，不代表实物已退回。
- **两条独立轴**：客户8D 是质量流程跟踪（单头 eightDNo，可伴随任意处理决定）；实物退回是物流事实（RMA 收货事件/时间轴节点，返修必须先收到实物才能开工），二者都不是处理决定枚举值。
- 生成 RMA 编号跟踪。
- 退货返工发起独立返工工单（执行在生产/品质侧），业务跟踪进度并回复客户。
- 退货结果联动财务（退款、折让、补发不另收费等）。

## 9. 发票申请

- 业务按订单/出货记录提起**发票申请**：选择客户、关联出货/对账记录，系统自动带出金额、税率、发票种类（普票/专票，来自客户档案）与开票信息（抬头、税号、发票地址）。
- 申请流转财务开票；状态跟踪：已申请 → 财务已开票 → 已寄出/已签收。
- 发票与订单、出货、应收自动关联，供对账单与数据分析引用。
- 红冲/作废须关联原发票并说明原因，由财务执行。

## 10. 报关资料

- 外贸主数据：客户英文名称地址、收货人/通知人、HS编码、英文品名、材质、原产国、贸易条款、运输信息。
- 出货审核后按实际数量、箱数、毛净重、币种、价格生成：形式发票、商业发票、装箱单、销售合同、报关数据包。
- 已提交版本只能更正或生成新版本，不能覆盖；申报回执归档。
- 汇率取当日汇率表并保存快照。

## 11. 数据分析

- **每日经营量**：每天的接单总量、出货总量、未完成订单总量（按日/周/月视图，可按业务员、客户钻取）。
- 报价分析：报价数量、成交率、未成交原因、报价周期，按业务员/客户/产品钻取。
- 订单分析：四类订单结构、订单额趋势、准交率、延期原因。
- 客户分析：客户订单额排名、毛利（报价成本 vs 实际成本偏差）、回款与逾期（引用财务）。
- 退货质量分析：RMA 数量、原因分布、重复问题。
- 审核时效：报价审核、订单审核各节点时长、按时率。
- **导出**：数据分析里所有报表均可导出为 Excel 下载。

## 通用规则（贯穿全部模块）

1. **图纸留存**：所有图纸统一进入系统图纸库，带版本号与上传人；报价环节上传的图纸自动流转给报价工程师（核价）和工程部（建BOM），任何单据只引用图纸库版本，不重复上传。
2. **所有表格可下载**：系统内全部列表与表格（报价、成本分析、订单、追踪、对账单、各类报表）均支持导出下载（Excel 为主，正式文件另有 PDF）。
3. 编号、审批流、通知、预警统一调用第0步系统管理平台能力。
4. 报价单、成本分析、订单在审核通过后锁定版本；修改一律生成新版本并保留旧版本。
5. 单据字段自设计起预留成本与凭证要素（金额、币种、税率、成本承担方、批次），供财务模块自动凭证使用。
6. 角色权限：成本分析仅报价工程师可创建/修改；业务员数据按负责客户过滤。

## 平台联动需求（第0步系统管理平台）

- **登录界面增加"申请账户"**：填写员工姓名、所属部门、用户名、密码。
- **唯一编码规则**：每个用户拥有唯一编码，在注册时单独生成；**用户名不是唯一编码**，仅作登录用途。
- **用户名释放规则**：账号注销/释放时**只释放用户名**（可被新用户复用），**不释放唯一编码**——历史单据、审批与审计记录永远指向唯一编码，不因用户名复用而错乱。
- 账户申请需管理员（IT/部门负责人）审批后生效，并分配角色权限。

## 模块间流程主线

```
询价(新/老客户, 业务只提供图纸+数量) → 成本分析(仅报价工程师, 相似匹配参考)
  → 报价单生成(业务员, 强制关联成本分析, 阶梯/非阶梯价+模具费单列, 低于成本拦截)
  → 业务经理审核 → 客户确认
  → BOM申请(正常单/备料单, 图纸自动传工程) / 免费或收费选择(样品单, 无BOM无品号) / 模具要求时间(模具单)
  → 下单(强制校验报价/成本分析/工程资料, 交期必填, 一单可多产品, 客户订单原件上传)
  → 订单评审 → 订单追踪(业务/总经办/PMC可见, 进度按完成数/工单数)
  → 出货管理(放行+信用校验, 一单多产品) → 发票申请 → 报关资料(国外) → 对账单 → 应收/回款
  → 退货管理(RMA/8D)
  变更分流: 改图/改材料/改表处→ECN; 改数量/改交期→订单修改申请; 改价格→报价单修改申请
```
