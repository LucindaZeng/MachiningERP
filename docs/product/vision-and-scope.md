# 产品愿景与范围

## 愿景

让订单驱动型机加工企业以一套可追溯的数据链管理“从客户图纸到现金回款”，让计划、现场、质量、仓储、供应商、客户和财务在同一事实基础上协同。

## 核心角色

| 角色 | 主要任务 | 关键数据限制 |
| --- | --- | --- |
| 业务 | 询价、报价、合同、订单、交期和客户沟通 | 不默认查看供应商底价、内部责任和未授权财务信息 |
| 工程 | 物料、图纸、BOM、工艺、程序、工装和变更 | 只能发布经过审批的有效版本 |
| PMC | MRP、齐套、产能、生产与交付计划 | 必须区分合格、冻结、在制、在途和已分配供给 |
| 采购 | 询价、比价、定标、下单、供应商进度和价格 | 可看授权供应商与行情明细，不得越权看客户价格 |
| 生产 | 派工、扫码、报工、异常、设备与人员绩效 | 不能跳过工序、检验和质量冻结 |
| 品质 | 检验、异常、MRB、返工、CAPA、8D 和放行 | 放行、让步和报废实行职责分离 |
| 仓库 | 收货、上架、备料、配送、盘点和库存状态 | 非仓库岗位不能直接修改库存 |
| 财务 | 总账、往来、资金、费用、资产、税务、成本和月结 | 工资、银行、成本和凭证按组织/字段隔离 |
| 老板/管理层 | 经营、交付、现金、库存、毛利、质量和风险 | 汇总与钻取仍受角色权限控制 |
| 供应商 | 报价、订单、进度、送货、质量和对账 | 只能访问自己的数据与受控文件 |
| 客户 | 项目、交付、发货、文件和客诉 | 只能访问自己的项目且看不到内部成本 |

## 系统范围

- ERP：经营交易、供应链、库存、外贸、财务和制造成本。
- PLM：工程主数据、图纸、BOM、工艺、变更和版本。
- MRP/APS：净需求、齐套、资源约束、排程和交期模拟。
- MES/QMS/WMS：现场执行、质量控制、仓储物流和追溯。
- SRM/客户门户：外部报价、订单、交付、文件、质量和结算协同。
- 金属材料价格中心：许可行情、供应商报价、历史采购、落地价、快照和影响分析。
- BI/AI：指标治理、驾驶舱、财务与老板问答、引用和审计。

## 产品原则

1. 业务发生时采集数据，后续单据、报表和凭证复用同一来源。
2. 编码、版本、批次、工序、状态、审批和审计是一等对象。
3. 正式文件由源业务数据生成；修改应回到源单并重新审批。
4. AI 默认只读，任何写回都只能形成草稿并走原审批。
5. 外部市场数据必须满足许可和可追溯要求，不能通过无授权抓取实现。
6. 先跑通垂直业务闭环，再扩大模块与智能化范围。

## 当前不承诺

- 尚未确定具体开发语言、数据库、云平台或 ERP 厂商组合。
- 尚未承诺自动执行交易、采购、付款、记账、质量放行或报关。
- 尚未承诺任意交易所行情都能免费、实时或对外展示。
- 规划文档不替代会计、税务、数据许可和网络安全专业意见。
