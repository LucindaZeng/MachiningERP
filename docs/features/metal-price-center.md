# 实时金属材料价格中心

## 目标

建立采购、财务和业务共享的材料价格事实层，同时通过角色和字段权限隔离供应商底价、成本、客户价格和行情许可范围。

## 价格层级

1. 市场基准：交易所官方或持牌数据商提供的现货、期货、结算或参考价格。
2. 供应商报价：包含牌号、形态、规格、数量阶梯、升贴水、加工、物流、税和有效期。
3. 历史成交：采购订单、到货重量、质量扣款、发票和最终结算形成的真实采购价。
4. 企业参考价：市场基准经汇率、升贴水、加工、物流和税费换算。
5. 业务快照：报价、采购、标准成本或分析实际引用的不可变价格版本。

## 数据模型

| 实体 | 关键字段 |
| --- | --- |
| MarketSource | 来源、许可类型、实时性、用途、用户范围、到期日和凭据引用 |
| Instrument | 交易所、品种、合约、交割月、币种、单位、时区和交易日历 |
| MaterialMapping | 企业材料牌号、形态、规格、基准品种、金属含量和换算规则 |
| MarketQuote | 买/卖/结算价、行情时间、接收时间、状态、质量评分和原始引用 |
| SupplierPrice | 供应商、规格、阶梯、税、升贴水、加工、运费、付款和有效期 |
| PurchaseActual | 订单、到货、重量、发票、扣款、币种、含税/未税和最终结算 |
| LandedPriceRule | 基准、汇率、单位、升贴水、加工、物流、关税和生效版本 |
| PriceSnapshot | 用途、来源、行情、公式、参数、结果、时间、审批和源单据 |
| PriceAlert | 规则、阈值、对象、角色、影响业务、责任、措施和关闭 |

## 落地参考价

```text
企业落地参考价
= 市场基准价 × 汇率 × 单位换算
+ 升贴水
+ 加工/切割费
+ 包装、运输和保险
+ 关税及不可抵扣税费
```

公式只是默认框架；不同材料、形态、产地、合同和组织使用受控版本，不允许把所有材料简单套用一个比例。

## 分角色能力

### 采购

- 市场、供应商报价和历史成交同屏比较；
- 查看偏离、趋势、有效期、数量阶梯和总落地成本；
- 发起重询价、锁价、采购变价和异常审批；
- 下单时冻结价格、汇率、公式和供应商报价版本。

### 财务

- 模拟价格变化对标准成本、在途、库存、在制、采购承诺和现金的影响；
- 分析材料价格差异、订单毛利和客户/产品风险；
- 模拟重估与法定存货账分离，正式调整遵循会计审批；
- 在月结和预算中识别行情快照过期或异常来源。

### 业务

- 查看经批准的参考价格、趋势、成本影响和报价有效期建议；
- 生成带行情快照的报价成本；
- 价格超过阈值时进入重新核价；
- 默认不能查看供应商身份、底价、议价过程和未授权财务字段。

## 实时性与质量

界面必须明确标识：实时、延时分钟数、日结、上一交易日或人工审批价。若接口延迟、缺失、异常跳变、币种/单位错误或许可到期，价格标记不可用于自动核价，并按规则回退或人工审批。

## 数据许可

接入前需确认数据源对内部展示、估值、定价、派生数据、缓存、用户数和再分发的许可。LME 官方说明其数据用于估值、定价或交易参考可能需要相应许可；实现中不得依赖无授权网页抓取。

官方参考：

- [上海期货交易所](https://www.shfe.com.cn/)
- [LME Market Data](https://www.lme.com/market-data)

## 预警

- 日内/日间涨跌超过阈值；
- 供应商报价相对市场或历史成交偏离；
- 客户报价使用的快照过期；
- 采购订单申请变价；
- 标准成本、库存、在制或订单毛利影响超过阈值；
- 行情中断、延迟、异常值、映射失效或许可到期。

## 验收

1. 用一条许可行情完成品种、牌号、单位、币种和时区转换。
2. 采购、财务和业务账号看到不同字段，但同一价格快照结果一致。
3. 报价和采购订单能按历史时点重现计算。
4. 行情变化触发预警，但不自动修改已审批订单或法定账。
5. AI 回答引用行情源、时间、许可状态、单位、快照和模拟假设。
