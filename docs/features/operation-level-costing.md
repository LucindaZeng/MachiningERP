# 工序级制造成本核算

> 本文件由 `tools/build_process_costing.py` 根据 `tools/process_costing.py` 生成，是ERP V2.0工序成本研发基线。

## 核算原则

- 成本最小核算颗粒度固定为“法人/工厂→销售订单→生产工单→批次/序列号→工艺路线版本→工序→工序执行实例”；同一道工序第二次执行、返工重做或改线后执行必须建立新的实例，不能覆盖第一次成本。
- 每一道实际执行工艺都必须单独形成成本，不允许把CNC、打磨、表处、镭雕、丝印、检验、组装和包装等合并成一个笼统加工费，也不能只在工单完工时填写总成本。
- 工序同时保存标准成本、预计成本、实际暂估成本和实际结算成本；各口径必须标识费率版本、数据截止时间、币种和状态，禁止混合比较。
- 上道工序累计成本随合格数量转入下道，本工序只新增本工序成本；系统既能看到本工序增量，也能看到截至本工序的累计成本和最终订单成本。
- 工序成本来源于业务事实：材料领退、人员报工、设备时长、刀具/工装使用、委外收货对账、检验、物流包装和制造费用分配；禁止由财务在月末脱离源单手工摊成总数。
- 工序投入、合格、不良、返工、报废、在制和转出数量必须平衡；品质负责质量判定，交出/接收岗位负责数量，财务使用审核后的数量和时间计价。
- 正常损耗、超额损耗、返工、报废、停机和等待成本分栏保存；是否进入合格品成本、质量损失或责任分析由批准会计政策决定，但原始成本事实永不删除。
- 订单、产品和客户成本由全部工序实例逐层汇总；任何汇总数字都能下钻到工序、人员、设备、材料批次、委外单、检验记录和凭证。

## 成本构成

| 成本组 | 必须归集的内容 |
| --- | --- |
| 直接材料 | 本工序实际消耗的原料、半成品补料、辅料、化学品、磨料、油墨、包装料等，扣除退料和可确认回收。 |
| 直接人工 | 准备、调机、加工、上下料、清洁、组装、包装和必要记录的审核工时/计件金额。 |
| 机器与能源 | 设备实际运行/准备时长×有效机时费率；可细分折旧、能耗、维修、租赁及设备辅助费用。 |
| 刀具与工装 | 刀具实际消耗、寿命分摊、专用夹具/模具/治具摊销、工装维修与一次性投入。 |
| 委外加工 | 该工序供应商加工费、最低批量、运费、保险、加急、损耗、返工、扣款及税务口径金额。 |
| 检验与质量 | 首检、巡检、末件、FAI、过程检验、委外回料检验、全检、OQC的人员、设备、耗材和外部检测。 |
| 物流与包装 | 工序间搬运、外发往返、清点、容器、标签、内外包装、装箱和发运准备。 |
| 制造费用 | 按机器工时、人工工时、产量、占用面积或其他批准动因分配的工作中心间接人工、折旧、能耗及管理费用。 |
| 异常损失 | 返工、报废、超额损耗、非计划停机、等待、插单、加班、交期罚款等，分栏显示是否进入产品成本。 |
| 回收与调整 | 供应商索赔、客户承担、残值、材料回收、责任扣款、价格/发票差异和跨期重算，单独列示而非直接抹除毛成本。 |

## 计算公式

| 指标 | 公式 | 控制 |
| --- | --- | --- |
| 本工序新增成本 | 直接材料＋直接人工＋机器/能源＋刀具工装＋委外＋检验＋物流包装＋制造费用＋按政策计入的异常－本工序回收 | 显示成本构成和源单。 |
| 本工序新增单位成本 | 本工序新增成本÷本工序合格转出等价数量 | 部分完工时使用批准等价产量；分母为零则禁止结算。 |
| 工序完工累计成本 | 上道转入累计成本＋本工序新增成本±批准调整 | 保留转入成本和本工序增量两栏，不能合并后失去来源。 |
| 合格品累计单位成本 | 分配给合格转出数量的累计成本÷合格转出等价数量 | 正常损耗、异常损失和在制分配按政策版本执行。 |
| 工序报废损失 | 报废数量承接的上道累计成本＋本工序已发生新增成本－残值/回收 | 归集到发生工序、原因和责任方。 |
| 工序成本差异 | 实际结算成本－标准成本 | 拆解材料价格/用量、人工工资率/效率、机器效率、委外价格、良率和费用分配差异。 |
| 订单实际成本 | Σ该订单全部有效工序执行实例实际结算成本＋订单级费用－重复抵销项目 | 包含返工重做实例；能逐层下钻。 |

## 完整流程

1. 工程发布BOM与工艺路线时，为每道工序维护成本采集模板、标准资源、标准时间、损耗、计价单位和成本中心；缺少模板的路线不得发布。
2. 财务发布材料计价、人工费率、设备/工作中心费率、刀具工装摊销、委外价和制造费用分配版本，明确生效期间。
3. 工单创建时按路线自动生成工序成本卡和标准成本快照；工序未执行前显示标准/预计成本，不能提前伪造实际成本。
4. 工序扫码开工、暂停、完工，人员、设备、材料、刀具工装、投入/合格/不良/返工/报废数量和时长同步进入该工序执行实例。
5. 委外工序从外发、加工、回料、检验到对账逐步形成暂估和结算成本；供应商发票迟到时保留原暂估并生成差异调整。
6. 品质完成本工序质量判定，交接双方确认实际转出数量；系统以审核数量和等价产量计算本工序单位成本及转下道累计成本。
7. 部分完工、拆批、合批或跨月时，按数量、重量、标准成本或批准动因分配转入成本和本工序新增成本，保存分配底稿。
8. 返工、重流和重复执行为新的工序实例，重新归集成本；原工序成本保留并按责任/质量损失口径分析。
9. 工单完工后财务运行工序成本结算，检查所有工序成本卡、数量平衡、未结委外、未审核报工和费用分配；通过后锁定版本。
10. 月结或迟到发票触发受控重算，形成新版本、差异凭证和影响订单/库存/毛利清单，不覆盖历史成本结果。

## 审批权限

- 工程负责工序编码、路线和标准资源，生产/后工序确认可执行性，财务审核成本采集与成本中心映射；任何工序不得使用“其他加工”长期替代。
- 人工、设备、工作中心、制造费用、刀具工装和委外标准费率由责任部门提供依据，财务测算并发布；重大变化由总经办批准。
- 操作员只能提交实际执行事实，班组长审核工时/数量和异常；操作员不能修改费率、成本金额或删除已审核报工。
- 工序报工、领退料、委外对账和质量结果更正必须走原业务调整流程；财务只能重算或冲销，不能直接改现场数量。
- 正常损耗、超额损耗、返工、报废、停机和等待的成本去向由财务政策配置，品质/生产提供事实与责任，重大损失由总经办批准。
- 工序跳过、替代、拆分、合并或路线变更必须引用工程/品质/PMC审批，新路线自动生成新的成本卡和版本。
- 工序成本结算由成本会计执行、财务负责人复核；存在未结工序、数量不平、负成本、无费率或重大异常时禁止工单结算和月结。

## 预警

- 工艺路线存在未配置成本采集模板、成本中心、计价单位、标准时间、标准损耗或有效费率的工序。
- 工序已开工/完工但未报人员、设备、材料、数量或时长，或只在工单末端录入一个汇总成本。
- 某工序新增成本为零/负数、实际成本显著偏离标准、费率过期、数据长期停留暂估或发生异常手工调整。
- 投入、合格、不良、返工、报废、在制和转出数量不平，或成本转出数量与实物交接数量不一致。
- 上道累计成本未转入、同一成本重复转入多个子批次、拆批/合批分配不平或工序成本链断裂。
- 委外工序已合格回料但没有暂估/对账成本，或供应商发票/价格差异超过阈值未处理。
- 返工/重流重复执行沿用原工序成本、未建立新工序实例，导致第二次成本遗漏。
- 某工序材料用量、人工效率、设备效率、委外价格、不良率、返工率或报废损失超过阈值。
- 工单申请结算或月结时仍有未关闭工序成本卡、未审核报工、未分配制造费用、未结委外或未定责任损失。

## 验收场景

1. 选择一张包含切料、CNC、打磨、委外表处、镭雕、丝印、全检和包装的真实脱敏订单，系统自动生成每道工序独立成本卡。
2. 分别录入材料、人工、设备、刀具/辅料、委外、检验和包材，证明每笔成本进入正确工序而非工单总额。
3. CNC完工后验证CNC新增成本和累计成本；转入打磨后验证打磨只增加自身成本，同时继承CNC累计成本。
4. 模拟部分合格、报废和留站在制，证明数量与成本按批准规则分配，报废损失能定位到发生工序。
5. 模拟返工重做CNC并继续重走后续工序，证明每次执行产生新工序实例和第二次成本，原成本不被覆盖。
6. 模拟委外暂估、对账和发票价差，证明成本版本和差异调整可追溯且不会重复计费。
7. 汇总全部工序成本应等于订单实际成本，并能从订单→工序→源单/报工/设备/人员/材料/委外逐级下钻。
8. 删除某工序费率或漏报工后，系统应预警并阻止工单结算/月结；补齐后才能锁定工序成本版本。
