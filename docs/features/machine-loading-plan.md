# 架机表与机台负荷管理

对应需求（思维导图-企划部/生产部）：系统自动生成初版架机表；PMC 可调整架机表和交付优先级；生产部考核架机率；共用资源冲突检查；平衡化生产。

## 架机表定义

架机表 = 按机台 × 时间段的上机计划：哪台机、什么时候、装哪个工单/产品/工序、用什么夹具程序、计划产出多少。它是 APS 排程结果面向车间的落地视图。

## 自动生成初版架机表

- MRP 确认后，系统按生产建议自动生成初版架机表，输入包括：工艺路线的可用机台清单、夹位数、每夹位加工时间、准备/调机时间、每台机日产能、班次日历、设备维护计划、人员技能矩阵和在制占用。
- 生成逻辑：优先满足交期 → 减少换型/开机次数（可与订单合批联动）→ 平衡各机台负荷。
- 初版架机表状态为"建议"，未经 PMC 确认不下发 MES。

## 共用资源冲突与调整

- 生成和调整时校验机台、夹具、模具、检具、程序和技术员共用冲突，冲突项红色标出并给出可替代方案。
- PMC 可拖拽调整机台、顺序和时间；每次调整记录调整人、原因、时间和对受影响订单交期的模拟结果。
- 插单、返工子订单和交付优先级变化触发重算建议，PMC 确认后生效并通知受影响机台。

## 架机率与执行跟踪

- 架机率 = 机台已排产时间 / 可用时间；按机台、班组、日/周/月统计。
- 对比架机计划与 MES 实际扫码开工：计划未上机、上机晚点、提前拆机进入偏差分析。
- 架机表下发后成为操作工"傻瓜式"任务清单的来源，操作工不能自行改变上机顺序。

## 平衡化生产

- 周/日计划层面显示各机台、各工作中心负荷率热力图，识别瓶颈和闲置。
- 系统建议拆批、转移可替代机台、调班或外发以拉平负荷；采纳建议同样走调整留痕。
- 平衡化目标：瓶颈工序满载、非瓶颈按节拍拉动、在制总量受控（与未完结工单监控联动）。

## 预警与报表

- 预警：机台负荷超上限、关键订单未排入、架机冲突未处理、计划已到未上机。
- 报表：初版/当前架机表（按机台/按订单两个视角）、架机率日报/周报、计划与实际上机偏差表、机台负荷平衡分析。
