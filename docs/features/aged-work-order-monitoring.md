# 长时间工单未完结监控

对应需求：长时间工单未完结的监控。除单工序超期预警外，系统必须从工单整体维度监控"开了很久还没关"的工单，防止在制、成本和交期黑洞。

## 监控对象与账龄口径

- 对象：所有已下达未关闭的生产工单、返工子订单、委外单、采购单和尾数处理单。
- 账龄 = 当前时间 − 工单下达时间；同时记录"停滞时长" = 当前时间 − 最后一次有效业务动作（报工、转序、检验、收发料）时间。
- 与标准周期比较：账龄超过该产品标准制造周期 × 系数（默认 1.5）即视为超龄。

## 账龄分层与升级

| 分层 | 条件（默认，可配置） | 动作 |
| --- | --- | --- |
| 关注 | 停滞 > 3 天 或 账龄 > 标准周期×1.2 | 黄色预警给工单责任人和 PMC |
| 超龄 | 停滞 > 7 天 或 账龄 > 标准周期×1.5 | 橙色预警，责任人必须填写原因和预计完结时间 |
| 严重超龄 | 停滞 > 15 天 或 账龄 > 标准周期×2 | 红色预警升级部门负责人，进入总经办超期看板 |
| 疑似死单 | 停滞 > 30 天 | 深红色，强制评审：继续、转尾数处理或关闭 |

## 强制关闭流程

- 疑似死单必须由 PMC 发起完结评审，生产、品质、财务会签，判定剩余数量走返工、入库、报废或取消。
- 关闭前校验数量平衡和工序成本完整性（复用工序成本月结检查）；关闭原因进入根因分析。
- 不允许直接删除工单；异常关闭的成本差异由财务确认后进入质量损失或管理损失科目。

## 报表

- 未完结工单账龄表：按部门、机台、订单类型、账龄分层统计，可下钻到工单和最后动作。
- 停滞工单原因分析：缺料、设备、质量冻结、委外、计划取消、客户暂停等标准原因占比与趋势。
- 月结前"应关未关"清单：作为工序成本月结检查的前置输入。
