# 尾数返工与入库（订单交付后收尾）

对应需求：业务订单交完后，剩余尾数（不良品、返工品、超交余量）的返工和入库必须有系统化流程，不允许账外滞留在车间或仓库。

## 定义

- 尾数：订单主批次已完成交付后，仍挂在该订单下未结案的剩余数量，包括待返工不良品、返工完成待处置合格品、超出订单需求的多余合格品和确认无法修复的报废品。
- 触发点：订单主批次发货过账后，系统自动盘点该订单在制、待检、冻结和已完工未发货数量，生成"订单尾数清单"。

## 处理路径

每一件尾数必须归入以下四条路径之一，禁止无路径挂账：

1. 返工后补交客户：生成返工子订单（复用[返工拆单规则](rework-cost-accounting.md)），返工合格后按补交发货流程出货，计入原订单交付数量。
2. 返工后入库：客户需求已满足时，返工合格品转为公司库存（备品/备料），按半成品或成品入库，入库成本取该批实际工序累计成本；后续订单可优先占用。
3. 直接入库：无质量问题的超交余量直接入成品库并与产品、图纸版本、材料批次关联，供后续订单或补货使用。
4. 报废：无法修复的尾数走报废审批，计入订单报废成本和责任分析。

## 控制规则

- 订单结案前系统强制校验：投入数量 = 交付数量 + 尾数入库数量 + 报废数量 + 在制返工数量，不平不得结案。
- 尾数入库必须保留原订单号、批次码和工序履历，一码到底不中断；后续订单占用尾数库存时自动带出谱系。
- 尾数返工成本按返工子订单独立归集，不冲抵主订单已确认成本；入库尾数按实际累计成本估价，与财务存货账一致。
- 图纸或工艺版本升级后，旧版本尾数库存自动标记"版本受限"，占用前需工程确认可用性。

## 预警

- 订单发货后 N 天（默认 7 天）尾数仍未定路径：黄色预警给 PMC 和业务。
- 尾数返工子订单超期未完成：按统一工序超期规则升级。
- 尾数库存超过保留期（默认 90 天）未被占用：转入呆滞物料分析。

## 报表

- 订单尾数清单：订单、产品、尾数数量、状态、路径、责任人、截止时间。
- 尾数入库与占用履历表：入库批次、成本、后续占用订单和结余。
- 尾数返工成本表：并入返工子订单成本明细表统计口径。
