# 数据与安全治理

## 数据分类

| 等级 | 示例 | 最低控制 |
| --- | --- | --- |
| 公开 | 已批准的产品资料、公开招聘和公开文档 | 发布审批和完整性保护 |
| 内部 | 一般流程、培训、非敏感配置 | 登录、角色权限和审计 |
| 机密 | 客户图纸、供应商报价、BOM、工艺、库存、质量、成本 | 组织/行/字段权限、加密、水印、下载审计 |
| 严格机密 | 工资、银行、个人信息、密钥、生产备份、模型凭据 | 最小人员、职责分离、强认证、专门审批和告警 |

## 数据所有权

- 业务：客户、询价、报价、合同和订单；
- 工程：物料工程属性、图纸、BOM、工艺和变更；
- PMC：计划参数、优先级、齐套与承诺交期；
- 采购：供应商、询报价、采购与行情使用规则；
- 品质：检验、异常、放行、CAPA 和追溯；
- 仓库：库位、库存状态、批次和盘点；
- 财务：科目、往来、资金、成本、税务和法定报表；
- 数据治理委员会：跨域编码、指标和语义层。

## 权限模型

权限由角色、组织、数据范围、字段、操作、状态和时间共同决定。客户/供应商采用租户或强行级隔离；内部敏感成本、工资、银行和供应商底价使用字段级保护。

## 审计

以下事件不可关闭审计：登录、权限、主数据、图纸下载、报价、定标、订单变更、库存调整、质量放行、返工路线、报废、凭证、付款、成本重算、行情人工修正和 AI 问答。

## 保留与删除

历史交易原则上使用冲销、停用和失效，不物理删除。保留期限依据财务、税务、合同、质量、客户和数据保护要求配置。测试数据应脱敏并有到期清理计划。

## 非功能门槛

- 关键扫码和库存操作定义响应时间与离线补传规则；
- 财务关账、MRP、成本和报表定义批处理窗口；
- 门户、接口、行情和 AI 定义限流、降级和可用性目标；
- 备份与恢复必须定期演练并记录 RPO/RTO；
- 发布前执行权限、越权、接口重复、数据对账和灾难恢复测试。
