# 项目路线图

## Phase 0：治理与业务蓝图

- 冻结首期范围、角色、组织、审批和验收脚本。
- 确认财务、总经办、生产、品质、后工序、工程、PMC、采购、委外和行政十部门的责任与权限。
- 完成真实业务流程走查、现状数据质量评估和系统边界。
- 决定采购成熟 ERP 组合、定制开发或混合路线。
- 通过 ADR 确定技术栈、部署、身份、数据库和集成模式。

退出条件：项目委员会批准范围、预算、责任和阶段验收门。

## Phase 1：主数据与工程基线

- 组织、部门、岗位、班组、工作中心、人员、班次、劳务单位、客户、供应商、物料、图纸、BOM、工艺、程序、设备、工装、检验和库位。
- 财务科目、成本中心、税码、银行与期初规则。
- 编码、版本、生效、审批、导入和数据质量报告。

退出条件：关键产品能以唯一有效版本生成工单、检验和 MRP。

## Phase 2：经营、价格与业财闭环

- 报价、合同、订单、采购、委外、库存、基础生产、交付和外贸。
- 香港代生产客户勾选与正式订单70%价格自动换算；样品、模具及其他客户不换算，其他流程沿用普通订单。
- 实时金属材料价格中心、材料快照、供应商比价和报价联动。
- 应收、应付、资金、费用、资产、税务和自动凭证。
- 考勤采集、请假加班、异常、日报/月报和多劳务结算。

退出条件：真实订单完成报价到回款、采购到付款和业务财务对账；香港价格客户完成正式/样品/模具及未勾选客户四组价格规则验证，并证明价格以外流程不变。

## Phase 3：计划、质量、成本和追溯

- MRP、动态齐套、条码、批次和正反追溯。
- 首检、巡检、末件、FAI、IQC/FQC/OQC、跨序返工、CAPA 和供应商质量。
- 标准/实际成本、返工/报废成本和系统生成报表。
- 每道工艺独立成本卡、工序成本累计流转、单位成本、差异分析、在制与月结完整性检查。

退出条件：两类跨序返工、全部工序成本之和与订单成本勾稽、工序成本可下钻源单，并与关键报表通过真实 UAT。

## Phase 4：APS、MES、WMS 与设备

- CNC、车床、清洗、丝印、镭雕、打磨、振磨、全检包装、独立组装、有限排程、工序防跳和现场异常。
- 仓储收货、上架、拣配、余料、盘点和仓位图。
- 设备采集、维修、OEE、预警升级和离线补传。

退出条件：计划、现场、库存、质量和成本数据一致。

## Phase 5：门户、BI 与 AI

- 供应商/客户门户、多工厂与集团财务。
- 经营驾驶舱、指标语义层和统一钻取。
- 财务与老板 AI 问答、情景模拟、引用、权限和审计。

退出条件：外部数据隔离，AI 固定问题集与正式报表一致且不能越权。

## 推荐首个垂直切片

选择一张包含金属原料、三道以上工序、一次委外和检验的真实脱敏订单，依次实现：

1. 材料价格快照与报价成本；
2. 报价审批和订单；
3. BOM、工艺、MRP 与采购；
4. 供应商报价、订单和 ASN；
5. 领料、扫码、检验、跨序返工和完工；
6. 入库、发货、应收、应付和工单成本；
7. 报表、预警和 AI 只读问答。
