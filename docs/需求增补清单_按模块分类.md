# 需求增补清单（按十三部门分类）

> 说明：本文件收录 24 条业务需求，**原文一字不改**，仅按公司十三部门（财务部、总经办、业务部、工程部、PMC、采购、委外、仓库、生产部、品质部、后工序部、行政、IT）归类。
> 每条需求在「主责部门」下给出完整原文；在「协同部门」下只作关联指引，不重复改写原文。

## 1. 财务部

无主责条目，涉及以下条目：

- 关联条目 **（4）**：备料订单的生产成本与加权平均成本口径（原文见「业务部」）。
- 关联条目 **（22）**：发票申请（原文见「业务部」）。

## 2. 总经办

无主责条目，涉及以下条目：

- 关联条目 **（3）**：订单追踪总经办可见（原文见「业务部」）。
- 关联条目 **（20）**：工单进度条口径（原文见「PMC」）。
- 关联条目 **（24）**：每日接单、出货、未完成订单总量（原文见「业务部」）。

## 3. 业务部

**（1）** 报价管理里，需要有一个根据条件搜索曾经的报价单

**（2）** 每一份报价单都要强制关联成本分析

**（3）** 订单追踪可以让业务及时的查询到该产品进行到哪个环节。必须从订单评审开始追踪。类似于订单评审- PMC跑生产计划-采购计划-到料-原材料品质检-切料-调机-首件检测-车床-品质检- CNC-品质检-打磨-品质检-仓库-委外表处-仓库-品质检-镭雕丝印-品质检-包装-出货报告-入库。订单追踪同时总经办和PMC部门都要能看到

**（4）** 订单类型新增备料订单，备料订单意味着业务部不需要交货，备料订单完成后产品全部入库视为完成订单，而下正式业务订单时，可以关联相对应的备料订单，直到备料产品被用完。备料订单的生产成本和交备料的正式业务订单的生产成本相同。假设正式订单下单100个，备料单剩余20个，继续生产80。如果备料订单的单间生产成本为10块，正式订单的生产成本为12块。那么这张订单的平均生产成本为（10*20+12*80）/100

**（8）** 报价单和成本分析表都要可以导出为EXCEL

**（9）** 业务每次下单时，如果产品缺少报价单/成本分析/或者任何工程资料都要提示报错，显示不能下单

**（10）** 报价申请时，业务提供图纸和数量（可阶梯，也可非阶梯），报价工程师完成剩余的资料填写

**（11）** 报价单和成本分析单都可以选择多项然后合并导出到一张报价单/成本分析表上。

**（12）** 现有订单修改，价格和下单产品不能被修改

**（13）** 香港70%的价格做成一个权限，只有在业务部权限的人才能看到香港70%的价格设定，其他业务员都不能看到

**（14）** 客户交期为必填项

**（15）** 模具订单/业务订单 需要强制上传客户订单原件，样品订单有价格的需要强制上传订单原件

**（16）** 样品订单/模具订单/业务订单/备料订单/出货/退货需要可以一张单下好几项产品。而不是一张单只下一件产品

**（18）** 报价单必须强制上传图纸，报价单的图纸会在系统里传给报价工程师进行报价，也会传给工程进行BOM建立

**（19）** 报价单需要有报价单修改申请，业务提起报价单修改申请（直接提修改后的价格）- 报价工程师修改成本分析或驳回申请（需要填驳回理由）

**（22）** 业务部增加功能：发票申请 数据分析里所有的报表需要可导出为Excel下载

**（24）** 数据分析还需要包含：每天的接单总量，出货总量，未完成订单总量

另涉及：

- 关联条目 **（5）（7）**：样品无 BOM、无品号（原文见「工程部」）。
- 关联条目 **（6）**：订单信息类变更在订单管理里申请订单修改（原文见「工程部」）。
- 关联条目 **（17）**：业务员无权做成本核算（原文见「工程部」）。
- 关联条目 **（20）**：订单追踪工单进度条口径（原文见「PMC」）。

## 4. 工程部（含报价工程师）

**（5）** 样品没有BOM

**（6）** 改图、改材料、改表处属于ECN，改数量、改交期、改价格等订单信息在订单管理里申请订单修改

**（7）** 样品没有BOM也没有品号（但是样品需要入库，或许样品可以用通用品号），只有正式订单的产品才有品号

**（17）** 成本核算只有报价工程师才能做

另涉及：

- 关联条目 **（1）（2）（8）（10）（11）（18）（19）**：报价、成本分析、图纸分发与报价单修改申请中报价工程师的职责（原文见「业务部」）。
- 关联条目 **（9）**：工程资料缺失导致不能下单（原文见「业务部」）。
- 关联条目 **（12）**：改价走报价单修改申请（原文见「业务部」）。
