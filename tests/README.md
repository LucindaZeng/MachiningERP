# Tests

测试结构应同时覆盖技术正确性和制造业务正确性：

- `unit`：领域规则、计算、状态机和权限策略；
- `contract`：API、事件、文件和外部数据契约；
- `integration`：模块、数据库、消息和第三方沙箱；
- `e2e`：真实脱敏订单的端到端业务流；
- `permissions`：组织、行、字段、客户/供应商和 AI 越权；
- `reconciliation`：库存、往来、成本、总账、报表和 AI 数字一致；
- `performance`：扫码、MRP、成本、报表、门户和行情并发；
- `resilience`：接口重复、网络中断、补传、恢复和降级。

验收案例应引用稳定需求编号并保存预期结果和证据。
